## Description

FastAPI makes your first endpoint easy. Then the app grows, and you need logging, .env handling, a database, tests and a frontend. fastapi-startkit gives you all of that without leaving FastAPI and Python.

It's a modular, provider-driven framework: start with a plain web app and add each feature as a provider when you need it.

Get started:
uvx fastapi-startkit@latest init

What's inside:
• Interactive installer: pick your app, database and frontend
• Providers: register and boot services in one place
• Logging channels: daily files, terminal and Slack, switched with LOG_CHANNEL
• Async ORM: models, migrations and seeders through the artisan CLI (db:install, db:make:model, db:migrate)
• Testing: .env.testing loads automatically, plus HttpTestCase and RefreshDatabase
• Frontend: Vite + Inertia with React and hot reload
• AI agents: typed agents with tools, structured output and fakes for tests
