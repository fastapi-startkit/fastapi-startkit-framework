| [007](007-inertia-request-scoped-state.md) | 2026-10-09 | Inertia request-scoped state and middleware protocol fixes | Per-request shares, the fallback version and the root view now live in an `InertiaRequestState` context variable instead of the global `ResponseFactory`, so they no longer leak or overwrite boot-time configuration. The middleware checks the version before the handler and sends 409 with `X-Inertia-Version` and a reflash. It redirects empty responses back and treats `201 + Location` as a fragment redirect, except for prefetch requests. It appends to `Vary`. Page JSON is escaped with `html_safe_json`. |
| [008](008-inertia-prop-resolution-pipeline.md) | 2026-10-09 | Inertia prop resolution pipeline | One composable `Prop` (optional/defer+group/always/rescue/merge/prepend/deep_merge/match_on/once/scroll) resolved by a recursive `PropsResolver` that filters partial reloads by dot path (only/except, except wins), skips optional/deferred/already-loaded once props on first visits, rescues failures into `rescuedProps`, and emits `sharedProps`/`mergeProps`/`prependProps`/`deepMergeProps`/`matchPropsOn`/`deferredProps`/`scrollProps`/`onceProps`; mirrors inertia-omega, callbacks resolve sequentially for async ORM session safety. |
| [009](009-inertia-redirects-session-data.md) | 2026-10-09 | Inertia redirects, flash, error bags, history flags and in-memory session | `inertia/session.py` writes flash data, error bags, `clearHistory` and `preserveFragment` to the session immediately. A render takes them back out, so they appear exactly once and survive redirects and 409 reloads; the no-op `reflash()` is removed. Without a session they go to request-scoped storage and a warning is logged. Adds `ValidationErrors` (accepts pydantic and FastAPI errors), `InertiaRedirect` with `redirect`/`back`/`back_with_errors`, `location()` (409 for Inertia requests, 302 otherwise), `encrypt_history` (global or per response), the test-only `inertia.testing.FakeSessionMiddleware`; `errors` is a lazy shared prop, and `fastapi.referer.same_origin_referer` guards every back-redirect. |
| [010](010-inertia-page-errors-always.md) | 2026-10-10 | Inertia page errors as an always prop | `errors` is an always prop that consumes only newly flashed errors, so a partial reload with no new errors gets `{}`, and a partial reload for a different component leaves the flash for its own page. The rendered component is kept on the request state for that check. `with_all_errors` and the error-bag header still shape the value per request. |
